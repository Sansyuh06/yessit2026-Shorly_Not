Quantum-Inspired Cyber Threat Detection for Digital Signature Security

What is this project?

ShorlyNot is a quantum security framework that uses real quantum teleportation circuits to digitally sign and verify financial transactions. If someone tries to forge, replay, or tamper with a signature, the system catches it automatically using mathematical statistics (not AI/ML) and locks the bank.

The 30-Second Pitch

Imagine every bank transfer is signed using quantum physics — specifically, entangled Bell pairs and teleportation. A forger would need to guess the correct quantum corrections, which is statistically impossible (< 10⁻⁶ chance). Our system detects any forgery attempt using Hoeffding statistical bounds and escalates through 5 security stages, eventually locking the entire bank application.

What does it actually do?

🧪 skeleton/ — The Engine

  • QDS-T1 Protocol: Quantum Digital Signatures using Bell-state teleportation on Qiskit Aer
  • Q-STDF: Non-ML threat detection with 6-stage decision ladder
  • QKD (BB84): Quantum key distribution for session keys
  • PQC: AES-256-GCM protection for quantum correction bits

🏦 bank/ — The Proof

  • Mock banking app with login, transfer, and history
  • SOC Dashboard: Real-time security monitoring with threat visualization
  • Attack triggers: Forgery, Replay, Impersonation, Channel tamper, Unauth
  • Auto-lockdown: Bank blocks transfers when threats are detected

How does the quantum signature work?

StepWhat Happens
1. EncodeTransaction hash → Pauli eigenstate bits (|0⟩, |1⟩, |+⟩, |−⟩)
2. EntangleCreate Bell pair |Φ⁺⟩ = (|00⟩ + |11⟩)/√2 between Alice & Bob
3. TeleportAlice does Bell measurement, gets syndrome (m1, m2)
4. CorrectBob applies Pauli correction {I, X, Z, XZ} based on syndromes
5. VerifyBob measures in matching basis — compares to expected bit
6. DecideIf mismatch rate p̂ > τ (Hoeffding threshold) → FORGERY detected

The Math (Key Formula)

Hoeffding Threshold:
τ = p₀ + √(ln(1/δ) / 2n)

With defaults p₀=0.02, δ=0.01, n=64 → τ ≈ 0.210
An honest signer gets p̂ ≈ 0.02 (just noise). A random forger gets p̂ ≈ 0.50 (rejected instantly).

What makes this special?

  • Real quantum circuits — not simulated random numbers. Every Bell pair and teleportation runs on Qiskit Aer.
  • Zero ML — threat detection is pure mathematical statistics (Hoeffding inequality), fully auditable.
  • Provable security — random forgery acceptance probability < 10⁻⁶ for τ=0.21, n=64.
  • Clean architecture — bank never touches crypto. Single brain in skeleton/, consumed via API.
  • 45 passing tests — covering all 6 attack vectors plus payload-tamper binding, real circuit fidelity, and pipeline integrity.
